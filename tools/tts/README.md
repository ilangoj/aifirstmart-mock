# Voice models (not shipped)

Put the narration voice models here before running `python afm.py narrate record`.

- English (Kokoro): `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the kokoro-onnx GitHub releases.
- Tamil (AI4Bharat Indic-TTS): download
  https://github.com/AI4Bharat/Indic-TTS/releases/download/v1-checkpoints-release/ta.zip and unzip here, so that
  `tools/tts/ta/fastpitch/` and `tools/tts/ta/hifigan/` exist.
